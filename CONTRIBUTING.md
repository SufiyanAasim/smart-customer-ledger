# Contributing to Smart Customer Ledger

Thank you for your interest in contributing to Smart Customer Ledger!

## Branching Strategy

Follow these branch naming conventions:
- `feature/*` — New features
- `bugfix/*` — Bug fixes
- `refactor/*` — Code refactoring
- `docs/*` — Documentation updates
- `test/*` — Unit or integration test additions

## Commit Conventions

Use Conventional Commits:
- `feat:` New functionality
- `fix:` Bug fix
- `docs:` Documentation change
- `refactor:` Code refactoring
- `test:` Unit tests
- `chore:` Build scripts or maintenance
