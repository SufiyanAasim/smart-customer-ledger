# Smart Customer Ledger — v1.0.0

> *Codename: Index*

---

## 📖 Overview

Index is the foundational release milestone of **Smart Customer Ledger**, establishing the application's C# .NET 8 LTS ASP.NET Core MVC web architecture, ASP.NET Core Identity authentication portal, multi-branch data isolation, and baseline customer ledger management workflows.

This release establishes the 4-tier modular clean architecture (Domain, Application, Infrastructure, Web MVC) and implements initial CRUD operations across all core business entities.

---

## 🎯 Objectives

* Establish a clean 4-tier C# ASP.NET Core MVC project structure targeting .NET 8.0 LTS.
* Build user authentication and role-based access control (Administrator, Branch Manager, Cashier).
* Enforce strict multi-branch data isolation via `ICurrentUserContext`.
* Build responsive UI with dark/light mode persistent theme switching.

---

## ✨ Added

### 🔐 Authentication Portal & Role-Based Security

* `AccountController.cs` — ASP.NET Core Identity authentication with default administrator seed (`admin@scl.com` / `admin@584`).
* Claims-based `ApplicationClaimsPrincipalFactory` injecting `BranchId` into user sessions.
* Role-based policy enforcement across all web actions.

---

### 💳 Core Ledger Management Engine

* `CustomersController.cs` & `InvoicesController.cs` — customer profile and billing invoice management.
* `PaymentsController.cs` & `InstallmentPlansController.cs` — payment tracking and installment plan configuration.
* `CustomerInteractionsController.cs` — customer support and follow-up interaction logging.

---

## 🏛️ Architecture Decisions

**4-Tier Clean Architecture.** Clear separation between Domain entities, Application service contracts, Infrastructure EF Core DbContext, and Web MVC controllers.

**Multi-Branch Scoping.** Service-layer data scoping enforced on every query via `ICurrentUserContext`.

---

## ⚠️ Known Limitations

* Atomic ACID payment settlement workflows added in v2.0.0 Balance.
* Machine Learning credit risk scoring added in v7.0.0 Capital.
