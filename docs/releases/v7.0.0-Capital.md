# Smart Customer Ledger — v7.0.0

> *Codename: Capital*

---

## 📖 Overview

Capital is the current release of **Smart Customer Ledger**, introducing a from-scratch Logistic Regression payment-risk scoring model, Recency/Frequency/Monetary (RFM) customer segmentation engine, dedicated Smart AI Credit & Ledger Assistant view mode, dark/light theme switching, and system credits page.

Building on the multi-branch RDBMS foundation established across previous project releases, Capital completes the financial lifecycle with intelligent analytics and operational risk scoring.

---

## 🎯 Objectives

* Implement supervised Logistic Regression payment default risk scoring (`CustomerRiskScoringService`).
* Implement classic Recency, Frequency, and Monetary customer segmentation (`CustomerSegmentationService`).
* Provide a dedicated Smart AI Credit & Ledger Assistant mode (`/Analytics?mode=smart`).
* Enhance visual branding with high-resolution enlarged logo and persistent dark/light theme switcher.
* Provide system credits page featuring author profile and contact details (`/Home/Credits`).

---

## ✨ Added

### 🤖 Machine Learning & Risk Analytics

* `LogisticRegressionModel.cs` — from-scratch supervised machine learning model using Z-score normalization, sigmoid activation, and batch gradient descent.
* `RfmSegmenter.cs` — quartile-based customer segmentation (Champions, At Risk, Lost, Loyal).
* `AnalyticsController.cs` — operational risk and segmentation decision support screen.
* `vw_CustomerRiskFeatures` — analytics SQL view exposing customer financial metrics.

---

### 🎨 Visual & Theme System

* Theme Switcher — persistent dark/light mode toggle.
* User Menu Dropdown — unified header menu housing theme options, admin links, and red logout.
* Credits Page — author profile card for **Mohammad Sufiyan Aasim** with GitHub and email SVG buttons.
