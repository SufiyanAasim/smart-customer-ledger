# Smart Customer Ledger — v4.0.0

> *Codename: Chronicle*

---

## 📖 Overview

Chronicle is the fourth release milestone of **Smart Customer Ledger**, delivering comprehensive documentation, architectural manuals, database dictionary generators, and interactive Mermaid ERD visualization diagrams.

Chronicle provides complete technical documentation across system design, database schemas, and operational procedures.

---

## 🎯 Objectives

* Create detailed database dictionary covering all tables, columns, indexes, and constraints.
* Add Mermaid ERD diagrams illustrating entity relationships and sequence flows.
* Create operational manuals (Installation, Configuration, User, Administrator, Troubleshooting).

---

## ✨ Added

### 📄 Documentation & Diagrams

* `docs/database/Database-Dictionary.md` — column types, constraints, and foreign key definitions.
* Mermaid diagrams covering entity relationships, authentication sequences, and payment flows.
* Operational guides for deployment, configuration, and troubleshooting.

---

## 🏛️ Architecture Decisions

**Self-Documenting Schema.** Database documentation is mapped directly from EF Core DbContext annotations and migration history.

---

## ⚠️ Known Limitations

* Primary/Replica database separation introduced in v5.0.0 Replica.
