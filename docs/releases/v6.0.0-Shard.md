# Smart Customer Ledger — v6.0.0

> *Codename: Shard*

---

## 📖 Overview

Shard is the sixth release milestone of **Smart Customer Ledger**, introducing logical database sharding, deterministic branch-to-shard routing (`BranchId % ShardCount`), and cross-shard revenue reporting.

Shard enables horizontal database partitioning across independent database instances while providing unified administrative reporting.

---

## 🎯 Objectives

* Implement deterministic branch shard routing via `IShardResolver`.
* Build `IShardDbContextFactory` for dynamic per-shard DbContext instantiation.
* Implement `CrossShardReportingService` aggregating branch revenue across active shards.

---

## ✨ Added

### 🔀 Sharding & Cross-Shard Aggregation

* `ShardResolver.cs` — deterministic modulus branch routing.
* `ShardDbContextFactory.cs` — dynamic connection string resolution per shard.
* `CrossShardReportingService.cs` — parallel query execution across shards with explicit failure handling.

---

## 🏛️ Architecture Decisions

**Partial Failure Visibility.** Cross-shard reporting executes independent queries per shard; if a shard is offline, partial results are returned alongside explicit failure alerts.
