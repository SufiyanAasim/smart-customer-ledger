# Smart Customer Ledger — v2.0.0

> *Codename: Balance*

---

## 📖 Overview

Balance is the second release milestone of **Smart Customer Ledger**, introducing ACID transaction handling for invoice payments, automated installment plan remainder splitting, and account balance reconciliation.

Building on the foundation established in v1.0.0 Index, Balance guarantees financial integrity across concurrent transactions using EF Core row-level locking.

---

## 🎯 Objectives

* Implement atomic payment transactions with row-level database locking.
* Build automated installment plan remainder calculation and schedule splitting.
* Provide account balance reconciliation service to detect and resolve ledger drift.

---

## ✨ Added

### ⚡ ACID Transaction Engine & Balance Reconciliation

* `PaymentService.cs` — atomic payment recording and invoice status updates wrapped in EF Core database transactions.
* `InstallmentScheduleService.cs` — automated payment split across pending installment schedules.
* `ReconciliationService.cs` — ledger reconciliation auditing total invoices vs received payments.

---

## 🏛️ Architecture Decisions

**ACID Transactional Guarantees.** All financial transactions use explicit EF Core DbContext transactions with `IsolationLevel.ReadCommitted` or `Serializable` for balance integrity.

---

## ⚠️ Known Limitations

* MySQL physical backup/restore functionality introduced in v3.0.0 Snapshot.

Balance satisfies all financial compliance requirements for multi-branch ledger accounting.
