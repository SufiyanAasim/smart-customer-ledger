# Smart Customer Ledger — v3.0.0

> *Codename: Snapshot*

---

## 📖 Overview

Snapshot is the third release milestone of **Smart Customer Ledger**, introducing native MySQL database backup and restore engines (`mysqldump`), CSV and JSON data export utilities, and preview-before-write CSV customer importing.

Snapshot provides robust disaster recovery and data portability across all branch locations.

---

## 🎯 Objectives

* Implement database backup and restore service using `mysqldump` and `mysql` binaries.
* Build CSV and JSON export utilities with formula injection neutralization.
* Build CSV customer import parser with preview validation.

---

## ✨ Added

### 📦 Backup, Restore & Data Utilities

* `MySqlBackupService.cs` & `MySqlRestoreService.cs` — database snapshot creation and recovery.
* `ExportService.cs` — neutralizes formula injection (`=`, `@`, `+`, `-`) during CSV generation.
* `ImportService.cs` — validates customer CSV rows prior to database insertion.

---

## 🏛️ Architecture Decisions

**Formula Injection Prevention.** All exported CSV cells are sanitized to prevent spreadsheet macro execution.

---

## ⚠️ Known Limitations

* Automatic Database dictionary generation introduced in v4.0.0 Chronicle.
